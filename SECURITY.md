# Security Policy

## Supported versions

Only the latest release of `appdata` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/VoIlAlex/appdata/security/advisories/new)
or by email to ilya.vouk@gmail.com. You should receive a response within a week.
